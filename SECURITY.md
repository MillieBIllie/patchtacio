# Security policy

Patchtacio is a security tool, so we treat problems in it seriously.

## Supported versions

Patchtacio is pre-release. Until v1.0, only the latest release (and `main`) gets security fixes.

## Reporting a vulnerability

**Please don't open a public issue.** Report it privately through GitHub:

1. Go to the [Security tab](https://github.com/milliebillie/patchtacio/security) of this repository.
2. Click **Report a vulnerability**.

Please include the affected version (`patchtacio version`), your OS, steps to reproduce, and the
impact you expect. Don't include real credentials or data from your own systems.

We'll acknowledge the report within 7 days and keep you updated as we fix it. Once a fix is
released, we'll publish a GitHub security advisory and credit you unless you'd rather stay anonymous.

## Wrong alerts

If Patchtacio **misses** an exploited or end-of-life product you run, or gets a match wrong, that's
a correctness bug. Please report it as a normal issue, unless the details would expose your own systems.
